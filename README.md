# User Management API

API REST desenvolvida com Spring Boot para gerenciamento de usuários.

## Tecnologias

- Java 17
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Maven

## Funcionalidades

- Criar usuário
- Listar usuários
- Buscar por ID
- Atualizar usuário
- Deletar usuário
- Tratamento global de exceções
- Validação de dados

## Endpoints

POST /users  
GET /users  
GET /users/{id}  
PUT /users/{id}  
DELETE /users/{id}

## Banco

PostgreSQL  
DDL auto: update
